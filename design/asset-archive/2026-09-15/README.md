# Historical website assets

These 44 files (40,137,370 bytes) were removed from the public delivery directory after checking the current source and generated HTML, JavaScript, CSS and JSON references. They remain here unchanged for future design work. Current Index/Intro films and posters, active Curation imagery, and the spatial Demo's current textures remain in `public/`.

`manifest.json` records each original path, archive path, byte size and SHA-256 checksum. Paths below this folder retain the original `public/assets/` structure. To restore an individual asset, copy its archived file back to the manifest's `original` path and confirm that the site actually needs it. Do not overwrite a newer asset at that path.

This reduces the deployed files, not the Git repository size. These are source/reference materials and are not served by Astro.
